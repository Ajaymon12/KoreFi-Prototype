## Using tokens in code

All tokens live in [`src/app/foundation.css`](../src/app/foundation.css), imported by `globals.css`.

| Need | Use | Example |
|---|---|---|
| A semantic colour | the alias CSS variable | `bg-(--color-background-secondary)`, `text-(--color-text-secondary)` |
| A raw scale step (rare: illustrations, charts) | the base variable | `bg-(--blue-900)` |
| A text style | `text-<style>` utility (+ `font-medium` for Bold) | `text-body-md`, `text-page-title`, `text-body-sm font-medium` |
| Corner radius | `rounded-<token>` | `rounded-medium` (buttons/inputs), `rounded-large` (cards) |
| Spacing | Tailwind's 4px scale (table below) | `gap-2` = Space8, `p-6` = Space24 |

**Rules**

- Use **alias** tokens in UI. Base colours are for data-viz and illustration only.
- Never hard-code hex values or Tailwind palette colours (`bg-orange-500`) in product UI.
- Theme is chosen by class: `.light` (default) or `.dark` on any ancestor. Tokens re-resolve inside nested scopes, so a `.light` panel can sit inside a `.dark` page.
- The base font is **Google Sans Flex** (⚙️ Typography → Font family/Base Font), loaded globally in `src/app/layout.tsx`.

## Spacing

Spacing tokens control gap and padding. In Figma they're scoped to **Gap**; in code use the matching Tailwind step.

| Token | Value | Tailwind | Usage |
|---|---|---|---|
| Space0 | 0px | `0` (e.g. `gap-0`) | No space. Flush layouts and resets. |
| Space2 | 2px | `0.5` (e.g. `gap-0.5`) | Hairline gaps: icon to badge, very tight inline items. |
| Space4 | 4px | `1` (e.g. `gap-1`) | Tight gaps: icon to label, chip and tag internals. |
| Space6 | 6px | `1.5` (e.g. `gap-1.5`) | Compact control padding and dense lists. |
| Space8 | 8px | `2` (e.g. `gap-2`) | Default gap between related inline items; small component padding. |
| Space12 | 12px | `3` (e.g. `gap-3`) | Gap inside buttons and form fields; list item spacing. |
| Space16 | 16px | `4` (e.g. `gap-4`) | Default component padding: cards, inputs, menus. |
| Space20 | 20px | `5` (e.g. `gap-5`) | Gap between related groups inside a section. |
| Space24 | 24px | `6` (e.g. `gap-6`) | Card and modal padding; gap between form rows. |
| Space32 | 32px | `8` (e.g. `gap-8`) | Spacing between blocks inside a page section. |
| Space52 | 52px | `13` (e.g. `gap-13`) | Spacing between major page sections. |
| Space84 | 84px | `21` (e.g. `gap-21`) | Page margins and hero spacing. |

## Grid

The Foundation's 🪟 Grid page is in **Beta** and currently has only its description ("The grid is the foundation for positioning content on a screen") and no layout grids defined yet. Until it does, product layouts use the app shell's fixed regions (top bar 48px, icon rail 64px, sidebar 256px) with Space24 page padding.
